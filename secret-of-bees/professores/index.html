A regra

Cabe numa frase

Melbees junta Forca e Campo Minado num favo de mel. Cada número de Pólen é uma pista: ele diz quantas letras certas são vizinhas daquele hexágono. Com essa lógica, decida se cada letra é para combinar ou descartar. Um erro custa uma pétala.

  1. Entregue uma folha por aluno ou por dupla. Leva de 10 a 20 minutos.
  2. O aluno marca ✓ ou ✕ em cada hexágono fechado: ✓ para combinar (a letra está no segredo), ✕ para descartar. No fim, escreve os dois segredos.
  3. Na correção, use o gabarito das últimas páginas: cada marca errada custa uma pétala.
  4. Depois, converse sobre as palavras: o gabarito traz a definição de cada uma.
