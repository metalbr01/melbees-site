We went looking for the oldest speedrun record still standing, checking the main categories of 10 games on the speedrun.com API. A winner showed up fast: Portal 2, Cooperative Game, 7:48.2, set on February 16, 2019. But before celebrating, we went and looked at the run. And the story changed.

What the API returned

  • Game and category: Portal 2, Cooperative Game, for two players.
  • Time: 7:48.2 (468.2 s), tagged as real time.
  • Date of the run: February 16, 2019, by a pair of runners.
  • Age: 2,836 days as of November 22, 2026.

For comparison, the median age of the 48 records in our query is 279 days. It looked like a runaway champion.

What's inside that run

The run page says something else. The pair's comment says they'd never run "course 6" before, and the demo file is named ch6. Portal 2's co-op campaign has six courses, and the community rules (rules.portal2.sr) define the main categories like this: All Main Courses is courses 1 through 5, and Any% goes up to the end of course 5. Course 6 is optional. So the 7:48 looks a lot like a course 6 run, not the whole campaign. The run also has no subcategory set, which is why it sits at the top of the board when nobody filters anything.

We can't prove from the API alone that it's a single course. What we can say is what the rules and the comment show: it isn't any of the three current subcategories.

The campaign records, once you filter

We queried the Cooperative Game board one subcategory at a time:

  • All Main Courses: 25:13.333, set on October 23, 2026.
  • Any%: 17:42.567, set on December 12, 2021.
  • All Courses: 33:29.2, set on October 23, 2026.

The oldest of the three, Any%, is 1,806 days old, almost 5 years. That's still well past the 279-day median, but far from the 7 years and 9 months the raw list suggested.

Which stopwatch counts here

For Portal 2, the API tags the time as real time. But according to the community rules, most runs are timed from the demo file the game itself records, which the SAR plugin reproduces. That's the same story as in any game: each community picks its own stopwatch, and the number you see depends on that choice.

So, what's the oldest?

With what we have, we can't say for sure. We only checked the Portal 2 run. The other nine games weren't checked subcategory by subcategory, so a 2020 or 2021 record on the list may or may not have the same catch. So we won't crown an "oldest" here.
