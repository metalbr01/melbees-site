Open a speedrun leaderboard for the first time and it looks odd: the same game has a 5-minute record and a 14-minute record, and both are "world records". There is no contradiction. A speedrun leaderboard is really a collection of different challenges that share one game, and each challenge is called a category. This guide explains the three most common ones, with real times we queried on speedrun.com.

The three abbreviations, one line each

  • Any% ("any percent"): finish the game the fastest way the rules allow, without worrying about collecting everything. It is usually the shortest and most contested category.
  • 100%: finish the game while doing everything the category defines as complete, such as collecting every item or clearing every stage. What counts as "everything" changes from game to game.
  • Glitchless: finish the game without the glitches that the community has decided to ban. The list of what counts as a glitch also changes from game to game, and each game's leaderboard decides.

There are many others, like "no skipping stages" or "one kind of item only". A category's name is a summary of its rules: it is always worth clicking and reading the description.

Why is there not a single record?

Because comparing times only makes sense between runs that follow the same rules. If we put them all on one board, the record would always belong to the most radical shortcut, and a glitchless runner would never appear. Categories separate what is comparable. Each has its own history, runners and world record.

The numbers that show the difference

On November 22, 2026, speedrun.com listed these best times:

  • Portal (2007): Out of Bounds, 5:00.735; Inbounds, 7:13.425; Inbounds No SLA, 8:53.13; Glitchless, 14:23.43. The glitchless category takes 2.9 times as long as Out of Bounds: without the glitches, the route is almost three times longer.
  • Celeste (2018): Any%, 24:44.083; All Hearts, 49:53.836; 100%, 1:37:16.372. The 100% run is 3.9 times longer than Any%.
  • Super Mario 64 (1996): 0 Star, 6:14.19; 16 Star, 14:32.87; 70 Star, 46:11; 120 Star, 1:35:14. Here the categories are laddered by star count: 120 stars take 15 times as long as none.
  • Hollow Knight (2017): Any%, 4:29.34; Low%, 10:53; All Skills, 26:38; 112% APB, 1:12:24. The longest is 16 times the shortest.

The same game can have a run under five minutes and another over an hour, and all of them count as the "world record" of their category.

How to pick where to start

  • Want to watch? Start with Any%: the shortest run and the one with the most tricks.
  • Want to understand the game? Watch glitchless: it shows the "normal" route pushed to perfection.
  • Want to see endurance? Pick 100%: hours of flawless execution.
  • Want to run yourself? Pick the shortest category of a game you already know: finishing a run is worth more than hours practising one that never ends.
Does Any% mean anything goes?

No. It means the percentage of items does not matter. What counts is what that leaderboard's rules allow, and each leaderboard writes its own rules.

Is one category's record worth less than another's?

Each measures a different challenge. 100% is longer and demands another kind of stamina. Any% is shorter and demands another kind of precision. Comparing the values makes no sense, only the positions inside the same category.

Where do real time and in-game time fit in?

That is another layer: each leaderboard also decides which stopwatch counts. For example, the Hollow Knight Any% record is 4:29.34 without loading screens, but 6:38 in plain real time.
