O Favo de papel é um PDF grátis com seis desafios de Melbees para imprimir. Cada folha é um favo de verdade do jogo, no nível Intermediário, com dois Segredos tirados das palavras do próprio jogo e algumas jogadas já feitas. A partir daí, os números impressos decidem cada hexágono fechado. Um programa conferiu cada folha: os números levam a uma única resposta, e essa resposta é a verdadeira.

São 9 páginas em A4: uma capa para o professor, os seis favos e duas páginas de gabarito. Funciona em preto e branco, e você pode imprimir e copiar à vontade para usar em sala.

Como usar

  1. Entregue uma folha por aluno ou por dupla. Leva de 10 a 20 minutos.
  2. O aluno marca ✓ ou ✕ em cada hexágono fechado: ✓ para combinar (a letra está no Segredo), ✕ para descartar. No fim, escreve os dois Segredos.
  3. Na correção, use o gabarito: cada marca errada custa uma pétala.
  4. Depois, converse sobre as palavras. O gabarito traz a definição de cada uma.

Para quem serve

Para professores de Português e de Geografia que querem uma atividade de palavras com raciocínio, para famílias que gostam de desafios no papel e para quem quer aprender a ler o Pólen antes de jogar. Os Desafios 1 e 2 são uma boa entrada. A página de estratégia resolve, passo a passo, parte dos Desafios 1, 3 e 4.
