Contact

Pour joindre Melbee Games, écrivez à contact@melbees.games.

De bonnes raisons d'écrire :

  • une question sur les règles ou un problème dans le jeu ;
  • un mot, un indice ou une anecdote qui semble faux (dans le jeu, vous pouvez aussi utiliser Envoyer un avis, dans Réglages → Compte, ou le signalement du mot sur l'écran des résultats) ;
  • une demande sur la confidentialité, vos données ou votre compte ;
  • la presse et les interviews (le kit presse contient la fiche technique, les textes et les images) ;
  • les écoles et les enseignants qui utilisent le Rayon de papier ;
  • une idée pour le jeu.

Plus il y a de détails, mieux c'est : indiquez l'appareil, la langue et ce qui s'est passé.
